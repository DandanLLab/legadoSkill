# 书源制作经验总结与案例

## 概述

本文档总结了在 Legado 阅读 APP 中书源制作的实战经验，包含多个真实书源案例和技术要点。每个书源都针对不同的网站架构和反爬机制，采用了差异化的解决方案。

## 二、核心技术要点

### 1. 搜索URL的发现方法

**核心原则：不要猜测，要分析**

#### 方法一：分析首页HTML
```html
<!-- 查找搜索表单的 action 属性 -->
<form action="/search.php" method="get">
  <input type="text" name="q" placeholder="搜索">
</form>
<!-- 搜索URL：/search.php?q={{key}} -->
```

#### 方法二：分析JS代码找API
```javascript
// 在JS文件中查找API调用
$.getJSON('/user/search.html?q=' + q, function(data) {
  // 返回JSON数据
});
// 搜索URL：/user/search.html?q={{key}}
```

#### 方法三：动态参数提取
```javascript
// 部分网站需要从首页提取动态参数
var html = java.ajax('https://example.com/');
var params = {};
var matches = html.match(/var\s+(\w+)\s*=\s*"([^"]+)"/g);
if(matches) {
    for(var i = 0; i < matches.length; i++) {
        var m = matches[i].match(/var\s+(\w+)\s*=\s*"([^"]+)"/);
        if(m) params[m[1]] = m[2];
    }
}
// 拼接搜索URL
var body = 'q=' + String(key) + '&sign=' + params.sign;
```

### 2. 正文获取的多种方式

#### 方式一：直接提取HTML
```json
{
  "ruleContent": {
    "content": "#htmlContent@html",
    "nextContentUrl": "text.下一章@href"
  }
}
```

#### 方式二：API获取正文（推荐）
```javascript
// 通过API获取正文内容
var url = String(result);
var match = url.match(/book\/(\d+)\/(\d+)\.html/);
var bookId = match[1];
var chapterId = match[2];
var apiUrl = 'https://api.example.com/chapter?id=' + bookId + '&chapterid=' + chapterId;
var jsonStr = java.ajax(apiUrl);
var data = JSON.parse(jsonStr);
var txt = data.txt.replace(/\n/g, '<br>');
txt = txt.replace(/广告文本.*/gi, '');
txt;
```

#### 方式三：备用域名切换
```javascript
// 当主域名失效时自动切换备用域名
var domains = ['api1.example.xyz', 'api2.example.xyz', 'www.example.com'];
for(var i = 0; i < domains.length; i++) {
    try {
        var apiUrl = 'https://' + domains[i] + '/api/chapter?id=' + bookId;
        var jsonStr = java.ajax(apiUrl);
        if(jsonStr && jsonStr.includes('txt')) {
            source.setVariable(domains[i]);  // 保存可用域名
            // 处理正文...
            break;
        }
    } catch(e) {
        continue;
    }
}
```

## 四、经验总结

### 4.1 搜索URL发现

1. **先看HTML**：查找搜索表单的 `action` 和 `name` 属性
2. **再看JS**：很多网站使用JS动态加载搜索结果，API隐藏在JS文件中
3. **动态参数**：部分网站需要从首页提取参数（如签名、token），通过正则匹配JS变量
4. **POST vs GET**：如果搜索表单是POST，书源配置也需要用POST

### 4.2 正文获取策略

1. **直接HTML提取**：最简单，适合静态页面
2. **API提取**：推荐，性能好、结构清晰，需要从HTML中发现API
3. **备用域名**：正文API域名经常变化，准备多个备用域名
4. **WebView验证**：遇到验证页面时，使用 `java.webView()` 等待验证完成
5. **域名缓存**：使用 `source.setVariable()` 缓存可用域名

### 4.3 详情页规则

1. **CSS选择器**：适合结构清晰的页面
2. **Meta标签**：适合API型网站，`[property$=xxx]@content` 格式通用
3. **JS init**：需要从页面提取变量时使用 `init` 字段
4. **tocUrl**：如果详情页和目录页是分开的，需要配置 `tocUrl`

### 4.4 目录分页

1. **单页目录**：`chapterList` 直接提取
2. **下拉选择器**：`nextTocUrl: "select@option@value"`
3. **JS生成URL**：返回URL数组，Legado会自动遍历

### 4.5 发现规则

1. **分类+排行榜**：混合配置，提供丰富的浏览入口
2. **URL格式**：使用 `{{page}}` 作为页码占位符
3. **规则复用**：如果发现页和搜索页结构相似，可以复用 `ruleSearch` 的规则

### 4.6 常见问题处理

| 问题 | 解决方案 |
|------|---------|
| 搜索页无封面 | `coverUrl: ""` |
| 信息合并（分类\|作者） | 使用正则拆分：`##.*\| |作者：##` |
| 正文分页 | 配置 `nextContentUrl` |
| 动态参数搜索 | 首页提取参数，JS生成搜索URL |
| 编码问题 | `charset: "gbk"` 配置 |
| 验证页面 | `loginCheckJs` 或 WebView 处理 |

```javascript
function getBaseUrl() { return 'https://example.com'; }

function refreshCaptcha() {
    var url = getBaseUrl() + '/api/captcha.php?r=' + Math.random();
    java.startBrowser(url, '验证码');
}

function login(b) {
    if (b == undefined) return true;
    var info = result;
    var mobile = info['手机号'];
    var password = info['密码'];
    var captcha = info['验证码'];
    if (!mobile || !password || !captcha) {
        java.toast('请完整填写手机号、密码和验证码');
        return;
    }
    var url = getBaseUrl() + '/api/auth.php';
    var body = 'action=login&mobile=' + encodeURIComponent(mobile)
             + '&password=' + encodeURIComponent(password)
             + '&captcha=' + encodeURIComponent(captcha);
    var post = JSON.stringify({
        method: 'POST',
        body: body,
        headers: {'Content-Type': 'application/x-www-form-urlencoded'}
    });
    var resp = java.ajax(url + ',' + post);
    try {
        var json = JSON.parse(resp);
        if (json.code === 0) {
            source.putLoginHeader(java.getCookie(getBaseUrl()));
            java.toast('登录成功');
        } else {
            java.toast('登录失败：' + json.msg);
            refreshCaptcha();
        }
    } catch(e) {
        java.toast('登录异常：' + e.message);
    }
}

function logout() {
    source.removeLoginHeader();
    java.toast('已登出');
}

function checkin() {
    var url = getBaseUrl() + '/api/checkin.php';
    var post = JSON.stringify({
        method: 'POST',
        body: 'action=checkin',
        headers: {'Content-Type': 'application/x-www-form-urlencoded'}
    });
    var resp = java.ajax(url + ',' + post);
    try {
        var json = JSON.parse(resp);
        if (json.code === 0) {
            java.toast('签到成功：' + json.msg);
        }
    } catch(e) { }
}
```

### 6.2 正文加密与解密

#### 方式一：XOR异或解密
```javascript
// 正文内容被 data-obf 属性存储，Base64编码后XOR加密
var html = result;
var matches = html.match(/data-obf=\"([^\"]*)\"/g);
var decoded = '';
if (matches) {
    for (var i = 0; i < matches.length; i++) {
        var obf = matches[i].match(/data-obf=\"([^\"]*)\"/)[1];
        var bytes = java.base64DecodeToByteArray(obf);
        for (var j = 0; j < bytes.length; j++) {
            bytes[j] = bytes[j] ^ ((j % 127) + 1);
        }
        decoded += java.bytesToStr(bytes, 'utf-8') + '\n';
    }
}
decoded;
```
